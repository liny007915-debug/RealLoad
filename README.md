暖白与石墨黑的三维装载工作台。逐件规格、自由摆放、透明柜体、四视图和装卸预演，均使用同一套真实坐标。宣传片采用实际界面录屏、合成测试货单与原创配乐。

Release 同时提供本地运行包、1080p 宣传片、封面、中文字幕、含素材的可编辑视频工程及 SHA-256 校验值。视频制作说明见 [promo/README.md](promo/README.md)。

用于装柜摆放、检查和逐件装卸预演的本地工作台。尺寸统一为 mm，重量为 kg，三维图形与计算共用同一份位置。普通使用没有需要安装的 npm 依赖。本版是可分享试用的测试版，尚未完成真实 Safari、实体手机或 Windows 实机验收，也不是运输安全认证工具。

## Mac 启动

1. 确认已安装 Node.js 20 或更新版本。
2. 完整解压 `RealLoad-Studio-v1.27-Beta1-Mac-OneClick.zip`，进入 `RealLoad-Studio-v1.27-Beta1` 文件夹，右键 `启动RealLoad.command`，选择“打开”。浏览器通常打开 **http://localhost:4202**，端口被占用时以启动器显示地址为准。
3. 使用完毕后运行 `停止RealLoad.command`。

也可以在工程目录运行 `npm run dev` 并保持终端开启。请通过本地 HTTP 地址访问，不要直接双击 `index.html`；浏览器会限制 `file://` 的模块加载。

Windows 提供 `启动RealLoad.bat`，与 Mac 启动器共用 `launcher.mjs`，同样要求 Node.js 20 或更新版本；停止本目录服务可运行 `node launcher.mjs --stop`。本版尚未在真实 Windows 环境验收，提供脚本不表示已完成平台认证。

启动器按解压目录识别服务，已有同目录服务可复用，其他目录或程序占用端口时另选空闲端口。服务器只监听本机回环地址 `127.0.0.1`，不会自动开放给局域网。分享压缩包后，每位使用者在自己的设备运行、保存和导出数据。

## 本测试版改进

- **每件已装实物独立保留规格。** 修改货物清单中的模板尺寸、毛重、包装、名称、转向权限或堆码层数，只影响以后放入的货物。已装货物保留各自原尺寸、毛重、包装、名称、转向权限和堆码层数，以及编号、位置、锁定和自由草稿。同一个 SKU 可以同时存在多个实物版本，移动、旋转、重排、装卸和导出都按每件规格计算。分组、订单、紧急程度和交付站次等物流资料仍可同步更新。数量不能低于仍在柜内的件序号。
- **模板能保存，实物仍须能放下。** 更大的模板不会把已装小件放大；后续新增件仍必须通过箱体边界、门洞、碰撞、支撑、堆码和载重检查。重排失败保留原方案，不会用最新模板重新生成或删除旧件。
- **新增 18 件、16 类包装的混合规格测试货单。** `examples/v127-beta-mixed-specs.json` 包含同 SKU 的三种已装实物版本，以及采用第四版模板的待装库存，用于检查新旧件共存、导出回读、自由移动和装卸。箱体及全部货物均为合成测试参数，非厂家规格，详见 [测试货单说明](examples/V127-Beta-测试货单说明.md)。
- **保护无法读取的本机存档。** 原文无法解析或基本结构非法时暂停写回，显示恢复选择，可先下载原始记录，再明确选择使用新工作台。本机保存的待恢复备份也可从「更多 → 导出 → 下载待恢复原始备份」下载。浏览器数据不会自动上传。

以下近期改进继续保留：

- **收起清单仍保留完整场景。** 修复桌面折叠后工作区被压成44px，以及隐藏面板占据第二行的问题。反复展开、收起、刷新和跨尺寸切换均保留货物。
- **修改资料不再清空。** 模板规格更新保留已装实物原规格与原位置；SKU 编号和物流资料更新保留实物身份。非法输入或数量冲突时保留原方案和输入，逐项修正后再保存；数量不能静默截掉已装件。
- **导入与清空分开。** 表格仅追加或更新同编号，未提及的货物继续保留；仅资料或空坐标JSON也按更新处理。「更多 → 清空货物」或清单底部可独立选择仅清空位置、或清空清单与位置，取消不修改，执行后可撤销。含完整坐标的JSON继续用于打开另一份方案。
- **整理工作台层级。** 参考用户提供的TEMPO概念工作台，保留暖白石墨配色；清单标题、记录数与收起入口集中，操作随当前模块显示，低频说明退到底部。未复制参考图片、图标或代码。

以下既有功能继续保留：

- **自由摆放有两种方式。** 默认连续拖动，自动落地或叠放，移动底层时可联动上方整垛；关闭吸附后保留真实间隙。切换「自由草稿」可暂时悬空、重叠或移到柜外，按Z方向或三轴手柄调整高度，最后统一检查并应用。草稿单独保存在本机；应用前，装卸与导出使用原方案。碰撞、越界、支撑不足等问题可点击定位；恢复原方案和撤销都可用。
- **直接进入货物移动。** 打开自由摆放会退出预演、切回选择工具，有已装货物时默认显示编辑列表。拖动中始终显示位置或拒绝原因；无效自动落位在松手时恢复，Esc、失焦和触屏中断取消本次拖动。移动设置紧靠场景，大小屏与画面全屏均可操作。
- **新增自由移动练习。** 三层纸箱、独立纸箱和异形设备共5件，便于练习整垛移动、叠放、悬空草稿、修复与应用。所有货物尺寸和重量明确标注为模拟值，见 `examples/v125-free-placement.json`。

- **统一暖白与石墨黑配色。** 页面、选中状态、主按钮、功能指南、表单和弹出面板使用同一套中性色。红黄绿只承担明确状态与场景方向含义。
- **箱体草稿实时预览。** 模板改为紧凑选择器，内尺寸、门洞和载重集中编辑。有效草稿直接更新三维与四视图，保存前不写入原方案；恢复输入即回到已保存箱体。另有侧面、门洞比例示意。保存和重排按钮固定在底部，窄屏内部滚动。
- **门洞错误直接定位。** 默认保持已录入门宽高，可主动勾选随箱宽高保持门框余量，计算尺寸仍需实测确认。去掉没有物理依据的箱长宽比例硬限制，门洞边界、碰撞、支撑和载重检查继续生效。
- **启动失败可恢复。** 直接打开 HTML 会显示启动器说明；应用模块载入失败显示原因与重试，不清除已保存规划。

- **重新整理工作区。** 电脑端纵向功能导航紧邻资料与三维场景，减少顶部重复工具和空白；选中编辑在右侧，统计在底部。手机保留全宽场景。新增 `⌘/Ctrl+K` 功能搜索，方向键选择、Enter 打开，直接到实际操作入口。
- **装卸路线比较。** 同时校验常见路线和关键障碍坐标上的 A* 候选，按均衡、少抬升或路程优先选取路线。可以限制卸出时相对原货位的额外抬升高度；0表示不再抬升。显示路程、累计抬升、最大单件抬升及清障步骤，每段仍通过连续外廓、门洞和支撑校验。装入按已验证卸出路径反向执行，抬升统计按装入方向重算。
- **多层清障与完整指南。** 清障优先级沿阻挡链传递，考虑后方急件、交付站次及主动指定目标。步骤解释为什么先处理该件。新手入口同时提供六步快速入门、20项可搜索功能说明、直接定位控件及返回指南；首次完成或跳过后默认不重复。计算设置随完整 JSON 备份保存。

- **箱体编辑可以完成。** 内尺寸、门洞和载重输入保留草稿，回车保存。冲突直接显示原因；可选择按新尺寸重排已装货物，保留编号和未装库存，失败不改原方案。锁定件保留原位，保存和重排都支持撤销。全屏下也可从「箱体外观 → 编辑内尺寸、门洞与载重」进入。
- **自由移动更稳定。** 首次选择不再挤动画布，拖动按当前视图平面移动：立体/俯视 XY、正视 YZ、侧视 XZ。选中后可设置步长、单轴约束或用六个方向按钮微调；自由摆放默认显示三轴手柄。手机打开「触屏移动」后拖货物，再点一次恢复滑动浏览。
- **轻重缓急与多站交付。** 新增 9 件、单件 6–860 kg 的模拟货单。紧急程度和交付站次可导入、修改和导出，并实际影响卸出排序：先清障，再按站次、同站按紧急程度处理。重量用于载重检查，不把重货自动当急件。

- **三维画面单独全屏。** 点击全屏或按 `Shift+F`，三维画布占满屏幕。视角工具浮在画面上，底部可打开货物、编辑和预演，也可收起工具专注看图；`Esc` 退出。不改变浏览器缩放比例。浏览器不支持时会提示并改用窗口铺满。
- **简洁的浅色工作台。** 暖白层次、石墨黑主操作，货物按列表排列。电脑上资料、场景和选中编辑相邻；手机全宽显示场景，资料在独立面板中打开，编辑紧接画布。规划名称仍可直接修改。
- **完整集装箱实物结构。** 波纹侧板、端板、顶板、上下梁、角柱角件、底部横梁、双开门、铰链、密封条和锁杆使用独立构件。右下角「箱体外观」可连续调节 0–100% 不透明度、切换剖面、调整开门角度。隐藏外观仍保留内尺寸边界与门向参照。内尺寸及门洞来自可编辑箱体资料，外部板厚及硬件为示意模型。
- **16 类货物构造。** 纸箱倒角与胶带、钉装木箱、缠膜整托、钢桶、卷材卷芯、木线盘、编织袋、机械面板、IBC 笼架阀门、空心管捆等采用不同几何和材质。原创纸板、木纹、织物和涂漆钢板贴图本地加载，来源与完整提示词见 [贴图说明](assets/materials/ORIGIN.md)。自定义照片材质仍优先使用。
- **智能装卸绕行。** 默认计算横移、升降、前后移动及先清障的顺序。每段检查固定朝向的外包络与门洞，动画按实际路径播放。保留严格直线模式用于对比。装入按验证过的卸出路径反向执行。
- **七组内置可编辑样本与独立 Beta 货单。** 内置日常混装 11 件、异形设备 7 件、门洞支撑边界 6 件、靠门大件绕行 3 件、轻重缓急多站交付 9 件、路径比较 2 件，以及自由移动 5 件。另可导入本版 18 件混合规格货单。货物全部使用模拟尺寸与重量，包含异形设备、线盘、管捆、纸箱、桶、整托等。JSON、CSV 与来源说明在 `examples/`。

规划命名、六步新手教程、导入导出和经过验证的几何内核均保留。教程首次完成或跳过后默认不再出现，可从“说明”重开或勾选下次仍显示。

## 基本流程

1. 点击顶部规划名称命名，从“货物”新建或“导入表格”读取 CSV、TSV、XLSX，确认字段、单位和错误行。
2. 在“箱体”核对实测内尺寸、门洞、载重。使用“一键装柜”或“自由摆放”，直接拖动货物，自动落地或叠放。需要暂时悬空或重叠时切换“自由草稿”，完成后“校验并应用”。只有通过边界、碰撞、支撑等检查的草稿才写入原方案。
3. 选择装入或卸出、智能绕行或严格直线，播放、暂停或单步。“播放设置”含退回、从头预演和速度；“装卸顺序与路径”含逐件编号和分段动作。受阻目标若可经清障取出，“装卸”列表提供“先清障”。预演期间原方案只读，退出后继续编辑。
4. 检查俯视、正视、侧视或四视图，从“更多 → 导出”保存完整方案 JSON 及清单。

可以先载入“靠门大件 · 清障与绕行”对比两种路径模式，详见 [绕行样本说明](examples/v120-绕行样本说明.md)。也可选择「轻重缓急 · 多站交付」查看单件重量、紧急程度和站次，详见 [模拟货单说明](examples/v122-轻重缓急样本说明.md)。载入前可取消，载入后可撤销。

新增「路径比较 · 平面与抬升」：路程优先时急件抬升200 mm越过低箱，少抬升时沿侧面通道绕行；卸出额外抬升设为0仍能找到平面路线。详见 [路径比较说明](examples/v123-路径比较样本说明.md)。这些是几何演示，不代表现场搬运设备可完成。

| 适配、聚焦 | `F` 适配整柜；选中货物后 `C` 聚焦 |
| 全屏画面 | `Shift+F` 进入或退出，`Esc` 退出；底部「收起工具」隐藏浮动界面 |

输入框中的编辑按键优先执行输入操作。选货不会自动放大到丢失柜体参照，需要时使用“聚焦”。

## 备份与迁移

完整 JSON 使用 `schemaVersion: 3`，保存已应用的规划名、箱体、SKU 模板、装载坐标、每件 `cargoSpec` 物理规格、路径模式、净空、路径偏好与卸出抬升上限，可重新导入。同 SKU 不同规格的实物不会在回读时统一尺寸。已装坐标与清单 CSV 按每件实物输出，待装行采用当前模板；CSV 与装卸建议用于核对，不能代替完整 JSON 备份。

未应用的自由草稿保存在当前浏览器，不包含在导出的正式方案中；迁移前请先修复并应用。旧 JSON 缺少名称、计算设置或单件快照时仍可按兼容规则读取，并依据当时文件中保留的资料建立单件规格。若旧版本已经覆盖了更早的实物尺寸且没有历史快照，本版无法反推出覆盖前的值，请根据原始货单或实测资料核对。

升级前先从原页面导出 JSON。不同端口、浏览器及 `file://` 有独立存储，不能依赖它们自动同步。兼容升级保留旧方案坐标；旧方案若不满足直线条件，可切到智能绕行重新计算，找不到路径时仍须调整摆放、朝向或设备。

项目数据和本地材质照片不自动上传，方案保存在当前浏览器本机存储。清理浏览器数据、切换地址或卸载浏览器可能失去本机记录，分享或迁移前请主动下载完整 JSON。启动器的本地 HTTP 服务仅提供本机文件，不是多人同步服务。

## 验证和适用边界

本版为 2026 年 11 月 3 日准备的 **1.27 Beta1 测试版**。实际通过项、失败项、限制和复跑方式以 [V127-Beta-测试与发布说明.md](V127-Beta-测试与发布说明.md) 及 [验收汇总 JSON](artifacts/v127/acceptance-summary.json) 为准。单元测试运行 `npm test`，浏览器测试需要已有 Playwright 和 Chrome/Chromium，普通使用不需要安装它们。

本次浏览器验证环境是 Chrome 软件 WebGL2 和模拟触屏。响应式模拟不能代替真实手机触控、Safari 渲染与全屏，Windows 启动器也尚未经过真实 Windows 实机测试。测试包可供收集反馈，不能据此宣称已完成上架、跨浏览器兼容或实际运输可靠性认证。

智能绕行假设单件被搬运、保持朝向、柜外暂存区空旷。异形与圆柱的路径按保守长方体外廓检查，不利用凹口和孔洞。未实现任意角旋转、叉车/吊具实体与承载、压力、绑扎、防滚、动态稳定性；搜索也有上限。几何路径可行不等于运输安全认证。实体手机、Safari 和实际搬运条件仍需现场核验。
