# RealLoad 原创产品展示配乐

`realload-product-60s.wav` 是本项目合成的原创轻电子背景音乐，不使用外部音乐、商业采样、音源包或人声。曲名为 **Quiet Assembly**。音色、和声、节奏和编排全部由同目录脚本直接生成；没有系统 TTS。

- 时长：60 秒，96 BPM，24 小节，4/4 拍。
- 文件：48 kHz、双声道、16 bit PCM WAV。
- 气质：柔和和弦、简洁琶音、少量高音回应，以及克制的低鼓与轻打击。
- 编排：前 10 秒逐渐进入；10–50 秒保持产品展示节奏；最后 10 秒减法收束。
- 淡入 1.4 秒，淡出 3.2 秒。峰值留出约 3 dB 数字余量。
- 当前成片版实测峰值为 −3.000 dBFS，整段 RMS 为 −16.402 dBFS，削顶样本数为 0。详细 peak、RMS、左右声道电平和 SHA-256 见 `realload-product-60s.json`。RMS 是整段、不加权的振幅测量，并非 LUFS；没有将样本峰值称为真峰值。

## 复现

使用 Python 3.10 或更新版本，以及已安装的 NumPy。脚本只依赖 NumPy 和 Python 标准库，不访问网络。

```sh
python3 promo/audio/generate_music.py
```

随机种子固定，相同依赖环境可重复生成相同文件。常规应用使用不依赖 Python 或 NumPy，这些仅供重新制作配乐。

## 循环和剪辑

当前 WAV 已为 60 秒成片做好片头片尾。产品片若缩短，按 2.5 秒一小节裁剪，在新片尾加 1–2 秒淡出即可。需要较长循环时，另生成没有片头片尾淡化、并把音符尾音衔接回开头的版本：

```sh
python3 promo/audio/generate_music.py --loop --output promo/audio/realload-product-loop.wav
```

`--bars 8`、`--bars 16`、`--bars 24` 分别生成 20、40、60 秒，更多长度按 8 小节递增。循环版始终保留完整和声周期；更改文件名可保留成片版。循环版请在视频时间线上统一加入片头片尾淡化，不要每个循环单独淡化。

配乐已留出峰值余量；视频剪辑可先以原音量的 0.65–0.85 试听。字幕展示不需要配音。如果后续增加人声，请按实际听感降低背景，不把此处的 RMS 数值当成平台响度标准。

本目录不包含第三方音乐授权负担。是否随项目公开，以及公开时使用的统一许可，由项目发布者决定。
