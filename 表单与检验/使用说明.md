# 表单与装柜验证包（V1.5）

**①** `01-可导入-空白模板.csv`：填写长宽高、单件毛重、数量、订单/组别，保留第一行列名。填写完成后导入。

**②** `02-可导入-14类示例.csv`：14 类完整示例，均为合成模拟数据，不是真实货物或厂家规格。也适合测试软件数据导入。

**③** `RealLoad-货物表单与校验.xlsx`：第一张是“货物导入”数据（14 个示例）；其他工作表是包装类型、检验清单和使用说明。软件只读取 Excel 第一张表，请不要把说明页移到最前面。

**④** `03-包装类别与校验说明.csv`：各货物种类对应的可用类型值、特点及风险。

**⑤** `04-装柜与现场核验表.csv`：用于现场填写，不应当作软件自动通过的安全认证。

内部数据单位：导入可使用 cm、mm 等长度单位与 kg、lb 等重量单位；计算内部使用 mm / kg。**装箱软件不验证叉车路径、固定、防滚、承压、VGM 或法规。**
