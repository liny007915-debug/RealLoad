工作区、计算设置与功能指南

电脑端采用紧邻资料和场景的纵向功能导航，常用操作放在场景上方，选中编辑在右侧。手机保留完整画布与独立货物面板。顶部查找功能或 ⌘ / Ctrl K 可搜索并打开功能，方向键选择、Enter 打开、Esc 关闭。

说明 → 全部功能提供20项可搜索说明，覆盖命名、样本、导入、货物与分组、箱体、自动装柜、自由移动、精调、触屏、视图、外观、全屏、材质、路径计算、播放、校验、导出、报价和快捷键。每项可直接定位实际控件，并返回原说明继续阅读。首次教程仍是六步，可跳过，默认不重复。

计算设置支持均衡、少抬升、路程优先，以及卸出时相对原货位的额外抬升上限。0表示卸出不再抬升；装入反向使用已验证卸出路径。显示总路程、累计抬升、单件最大抬升和清障步骤，不将代价换算为未经测量的实际工时。新增「路径比较 · 平面与抬升」模拟样本，可比较两种路线。

完整实物与全屏画面

右下角箱体外观可连续调节 0–100% 不透明度，切换完整箱体与剖面，调整双开门角度。箱体显示顶板、波纹侧板、端板、角件、门锁及铰链。内尺寸与门洞使用箱体资料，外部板厚及硬件是示意模型。16 类货物采用不同构造和本地原创表面材质。

点击全屏编辑或按 Shift+F，三维画布会铺满屏幕。底部可打开货物、编辑和预演，点击“收起工具”专注看图，“显示工具”恢复。Esc 退出并还原工作区，不改变网页缩放比例。

点击顶部规划名称可重命名。教程分六步，可跳过，完成或跳过后默认不再出现，“说明”可重开。当前测试结果、已知限制与复跑方式见 README.md、测试与发布说明及验收汇总 JSON。

当前装卸流程

选择装入或卸出，默认智能绕行计算横移、升降、前后移动及清障顺序；严格直线模式用于对比。播放、暂停、单步，以及播放设置中的退回、从头和速度共用一份路径。展开“装卸顺序与路径”可按编号回看。受阻目标可在“装卸”列表使用“先清障”。预演期间原方案只读，点击“退出预演”后继续编辑。

Mac / Windows 本地启动

解压 RealLoad-Studio-v1.27-Beta1-Mac-OneClick.zip，进入 RealLoad-Studio-v1.27-Beta1 文件夹，右键 启动RealLoad.command → 打开。需预装 Node.js 20 或更新版本。启动器自动打开浏览器，默认地址为 http://localhost:4202/。若端口被占用以启动窗口显示为准。

cd ~/Downloads/RealLoad-Studio-v1.27-Beta1
npm run dev

Windows 可双击 启动RealLoad.bat，与 Mac 共用 launcher.mjs，同样需要 Node.js 20 或更新版本。Windows 实机运行尚未验证。停止本目录服务可运行 node launcher.mjs --stop；Mac 也可打开 停止RealLoad.command。

启动器按目录识别自己的服务，已有同目录服务可继续使用，其他程序或副本占用端口时另选空闲端口。服务只监听本机回环地址 127.0.0.1，不会自动开放给局域网。请完整解压并通过本地 HTTP 地址打开，直接双击 index.html 可能被浏览器的模块加载规则拦截。

每件实物有自己的规格

货物清单是后续放入的模板。修改模板名称、尺寸、毛重、包装、转向权限或堆码层数后，已装货物仍保留各自原名称、尺寸、毛重、包装、转向权限、堆码层数及原位置。同一个 SKU 可以同时装有多个不同版本，不能用最新模板统一旧件。订单、分组、优先级和交付站次等物流资料仍可同步更新。

例如先放入一件纸箱，再把模板改成更大的木箱，原纸箱保持不变，下次放入才采用木箱规格。每件货物的移动、转向、装卸和重排都按自己的规格计算。更大的模板可以保存；新增实物仍须通过箱体边界、门洞、碰撞、支撑、堆码和总载重检查。非法输入、数量低于已装件序号或重排失败时，保留原方案，不静默删除货物。

更新资料和独立清空

编辑模板不会清空已装实物。表格追加与同编号更新不会移除未提及货物；仅资料或空坐标 JSON 也保留现有方案。含非空完整坐标的 JSON 用于打开另一份方案，导入前请先备份。

需要重新摆放时，从「更多 → 清空货物」或货物清单底部选择「仅清空装载位置」，清单仍可继续使用；选择「清空清单与装载位置」才同时清除货物。两者均可取消，执行后可用撤销恢复。收起资料面板不影响场景和货物。

备份、旧方案与存档恢复

通过「更多 → 导出 → 完整装载方案 JSON」保存备份。本版使用 schemaVersion: 3，每件已装货物带有 cargoSpec，保留不同版本的物理规格。已装清单按实物导出，待装行采用当前模板。未应用的自由草稿只在当前浏览器保存，迁移前请先修复并应用。

旧备份仍可按兼容规则读取；没有单件快照时，只能根据旧文件中现存资料建立规格。若旧版本已覆盖更早的尺寸且没有历史快照，本版无法反推出覆盖前的值。 请对照原始货单或现场测量核对。

本机存档无法解析或基本结构非法时，先显示恢复选择并暂停写回，保护原始文本。可先点「下载原始记录」，再明确选择「使用新的工作台」。本机保存的待恢复备份也可从「更多 → 导出 → 下载待恢复原始备份」下载。不要把无法读取的记录当成已自动修复。

项目数据和本地材质照片不会自动上传。各浏览器、端口和设备的本机存储彼此独立，清理浏览器数据可能丢失记录，分享或迁移前请主动下载完整 JSON。分享测试包后，每位使用者在自己的设备运行；本地服务不提供多人同步。

18 件混合规格测试货单

从导入入口打开 examples/v127-beta-mixed-specs.json，可检查16类包装、18件已装货物及1件待装库存。箱体与全部货物参数均为合成测试数据，不是厂家规格或实际运输案例。导入会打开其中的完整方案，先备份自己的方案。

其中 BETA-MIXED 的三件已装实物共用一个 SKU，依次为纸箱、木箱和设备，后续第4件采用当前冷链箱模板。修改模板后检查前三件保持原规格，再放入第4件、移动与旋转、重排、导出并重新导入，核对规格仍各自保留。步骤与数据明细见 测试货单说明。

修改箱体与柜门

点击「箱体」或「箱体外观 → 编辑内尺寸、门洞与载重」。输入实测数据后回车或点「保存尺寸」；未保存输入会保留，冲突显示在输入区。可用「按新尺寸重排已装货物」尝试缩柜，保留当前编号、锁定件及未装库存，失败不修改原方案，成功后仍可撤销。

轻重缓急与多站交付

测试场景「轻重缓急 · 多站交付」含9件模拟货物，单件6–860 kg，包含异形设备、整托、木箱、保温箱和轻货纸箱。先清障，再按交付站次、同站紧急程度安排卸出。货物资料中可编辑站次和紧急程度，也支持CSV/Excel字段映射及JSON备份。重量用于载重检查，尚未验证搬运设备承载能力。

自由移动与编辑已装

立体和俯视拖XY，正视拖YZ，侧视拖XZ。选中后用毫米步长、单轴约束、六个方向按钮和三轴手柄精调。手机先点「触屏移动」，拖完再点一次恢复页面滑动。自动落位会尝试地面和完整支撑面，未通过检查的位置松手后恢复。默认连续移动，移动设置可另开吸附和整垛联动。自由草稿允许暂时悬空、重叠和移到柜外，草稿单独保存在本机，修复后点击「校验并应用」。应用前，装卸和导出继续使用原方案。Esc、失焦或触屏中断会取消本次拖动。

点击导航中的自由摆放，有已装货物时默认打开 编辑已装。页面会显示每一件已装货物的编号、所属组别和 XYZ 坐标。通过搜索框过滤箱号或 SKU，点击一行就能在 3D 场景中定位；按住 Shift 可多选。行右侧的“···”和鼠标右键可打开该件的操作菜单。

货物分组：真正可以改

“货物”页点击管理分组，选择源组，勾选一条或多条 SKU，再填写目标组名，点击归组即可；点击“重命名此组”可修改整组。分组菜单还有“选中组内已装货物”，可以直接进入自由摆放执行批量移动、旋转和锁定。调整分组不会移动箱件 XYZ 坐标，也不会改变重量或尺寸。 实际来源编号保留；仅系统生成的 PLAN 编号随分组改变。

货物右键菜单

Mac 触控板使用双指点按，鼠标使用右键。对已装货物可以选择精确编辑、编号定位、选中同组、水平旋转、锁定、再放一件、复制箱件编号、移出货柜。所有操作也可以从已装列表、快捷键或右侧检查器进入。

早期功能说明：智能落位与直线预演

在导航中的自由摆放的“拖入货物”页，可打开“智能落位”开关。放置时优先尝试地面，如地面与已有货物冲突，会尝试堆在可完整支撑的货物顶面。仅对允许堆码的货物采用，不改变装箱安全约束。

在导航中的装卸，可以选择“卸出检查”查看柜门方向的直线通道；点击“生成建议顺序”，逐件选择“卸出”，场景只会隐藏模拟卸出的货物，不会覆盖原装载坐标。还可以切换“装入建议”查看卸货路径的反向参考顺序；导出 CSV 会列出建议装入/卸出记录。

装卸路径仅采用平移外包络及简化支撑判断，不模拟叉车、吊具、行走空间、绑扎拆除、包装形变及安全认证，不能直接据此指挥现场作业。

关于实物准确性

纸箱、木箱、托盘、桶装等渲染模型旨在帮助辨认包装，并不是厂家认证的实物数字孪生。当前碰撞与旋转校验主要使用外包络和有限圆柱接触规则，不能代替包装承压、叉车可达性、绑扎、防滚动、地板集中载荷和运输法规验证。本次浏览器验证使用 Chrome 软件 WebGL2 和模拟触屏。真实 Safari、实体手机和 Windows 实机尚未验证；模拟响应式与触屏不等于这些平台已通过。Beta1 供试用和收集反馈，不能据此宣称已上架或获得跨浏览器、现场运输可靠性认证。
