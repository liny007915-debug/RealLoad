# RealLoad Studio V1.18

本地运行的货柜装箱规划与装卸预演工具。尺寸统一为 **mm**，毛重统一为 **kg**。演示货物是练习数据，实际作业请使用实测外包装和设备尺寸。

## Mac 一键启动

1. 完整解压项目，安装 Node.js 20 或更新版本。项目无需执行 `npm install`。
2. 右键 `启动RealLoad.command`，选择“打开”。启动器会打开浏览器，默认地址为 **http://localhost:4202**。端口占用时，以启动器显示的实际地址为准。
3. 使用完毕后运行 `停止RealLoad.command`。

也可在项目目录打开终端运行：

```bash
npm run dev
```

## 第一次使用，先做三步

1. **放入一件。** 展开工作台“新手开始”，点击“试放一件”，练习选择、编辑和旋转。使用自己的货物时，点击“导入表格”，依次核对字段、单位和数据，再确认导入。
2. **形成方案。** 点击“一键装柜”，或在“自由摆放”中调整 XYZ、贴边和朝向。自动装柜按实际门洞范围排布；界面的基础几何检查和装卸路径检查需要分别核对。
3. **播放装卸。** 在画布下方“逐件装卸”选择“装入”或“卸出”，点击播放。可以暂停后继续、单步、退回一步、从头预演，并选择 0.5× 至 4× 速度。点击步骤编号回看并高亮对应箱体：装入显示该件完成后的状态，卸出显示该件开始前的状态。

装卸预演保留原方案坐标。装入动画要求目标布局基础几何有效，并能生成完整的严格直线顺序；无法通过时会说明原因。单件卸出后可以继续主播放器。

## 常用操作

| 操作 | 用法 |
|---|---|
| 页面滚动 | 非全屏时，普通滚轮滚动页面；手机在画布上滑动默认滚动页面 |
| 缩放场景 | `⌥/Alt`、`Ctrl` 或 `⌘` 加滚轮；全屏时普通滚轮也可缩放；也可点击 `＋/－` |
| 观察场景 | 拖动空白区旋转；`W/A/S/D` 环绕，`Shift+W/A/S/D` 平移 |
| 适配与聚焦 | `F` 复位全柜；选中货物后按 `C` 聚焦 |
| 全屏 | `Shift+F` 进入或退出；`Esc` 退出全屏 |
| 切换视图 | `1–5`：立体、俯视、柜门、侧视、四视图 |
| 编辑货物 | 点击选中；`R` 旋转 90°，`Shift+R` 转向 180°；方向键移动 XY，PageUp/PageDown 调整 Z |
| 撤销与重做 | `⌘/Ctrl+Z`、`⌘/Ctrl+Shift+Z` |
| 卸货面板 | `N` 卸下一件，`Shift+N` 先定位，`Backspace` 撤回一步 |
| 完整说明 | 点击“说明”或按 `?` 查看快捷键；输入框、按钮和弹窗中的按键优先执行控件本身的操作 |

常用视图、观察与移动、适配和全屏保留在画布工具栏；镜头、显示、材质和快捷键等选项在“更多工具”中。小屏的“场景外观”默认收起，分组与包装说明也可按需展开。步骤编号可左右浏览，货物清单可展开或收起；精确修改推荐使用 XYZ 输入和方向按钮。三维箱体、俯视图、柜门视图和侧视图共用实际放置坐标。

## 文件与旧版迁移

- **导入 CSV、TSV、XLSX：** 通过“导入表格”核对字段与单位。没有真实箱号时生成的 `PLAN-` 编号只是规划编号。
- **导出 JSON：** 保存柜型、货物资料和装载坐标，适合完整备份及重新导入。
- **导出 CSV：** 导出已装坐标或逐件清单，便于核对；装卸面板另有装卸建议 CSV。CSV 不是完整方案备份。
- **从旧版升级：** 先在旧版页面导出 JSON，再在新版通过“导入表格”选择该 JSON。不同端口属于不同浏览器存储来源，不要依赖本地存档自动迁移。

旧坐标导入后不会自动移动到新门洞范围。若门位不满足严格直线条件，请备份后自行调整，或重新一键装柜；基础几何不合法的 JSON 会被拒绝。

2026 年 10 月 31 日复验：单元及契约测试 **252/252**，浏览器流程 **14/14**，渲染检查 **7/7**，六组屏幕布局 **6/6** 通过。本机 Mac 启动器已完成原生 Terminal 冷启动和 HTTP 冒烟。测试范围、证据及未验证项目见 [V118-改进与验收.md](V118-改进与验收.md)。旧版说明保存在 [docs/README-v117.md](docs/README-v117.md)。

装卸仅模拟 **固定 Y/Z、沿 X 轴通过柜门** 的路径。非零净空还会检查箱间通道，因此门洞尺寸合格的方案也可能被拒绝。渲染材质用于辨认货物，不代表包装承压能力。软件没有认证叉车或吊具可达性、动态稳定性、绑扎及运输安全。移动端测试使用浏览器合成触摸，尚未覆盖实体 iPhone/iPad。
