# RealLoad Studio V1.5 · 自由摆放修复版

## 优先阅读：本版修复的交互问题

- **靠墙 / 角落**：落点在货物中心附近时，按完整外廓计算；靠近墙时可落到 `X=0`、`X=L-货物长`、`Y=0`、`Y=W-货物宽`，避免出现边缘一半越界后不能放入。
- **精确贴边**：进入「自由摆放」→「精确贴边」分别选择「靠柜头」「靠柜门」「贴左壁」「贴右壁」，选中多件时保持组内相对位置并重新校验全部几何约束。
- **透视落点**：Canvas 降级渲染改用数值反求地板投影的方式定位，修正靠边时的透视偏差。若视图与地板几乎平行，不能计算的位置会明确拒绝。
- **拖拽反馈**：拖入画布时显示可放置的毫米坐标或明确的错误原因，不再使用遮满画面的蒙层。移动中若发生碰撞、悬空或边界问题，会显示拒绝保存的提示。
- **移动贴边 / 成组**：鼠标拖动和三轴手柄会把货物尺寸纳入边界限制；多件拖动按整组外包络限制，不改变组内距离。
- **上手**：待装列表新增单击「放入」作为鼠标拖放之外的快捷操作，适合触控设备和初学者。
- **颜色/界面**：温暖纸白背景、橡木色材质、鼠尾草绿交互色；清理自由摆放时的重复场景按钮，保留工程与材质选项。
- **模型外观**：Canvas 降级视图加强桶、卷材、IBC、吨袋的结构区分；WebGL2 保留现有程序化 PBR 与自定义照片材质能力，**尚未完成 Mac GPU 实机质量验证**。

**限制仍然有效：** 圆柱/柔性包装依然按矩形外接尺寸保守计算；不模拟连续叉车路径、承压、绑扎或运输安全。贴墙不代表可从真实柜门搬运到位。此软件是规划原型，实际数据请现场核验。

# RealLoad Studio V1.0 — 实物材质与自由编排

**本项目是本地装柜规划原型，不是运输安全认证系统。** V1.0 延续 V0.9，在 V0.8 的导入/订单/编号/自动装柜之上新增“自由摆放”独立模块，扩展包装种类与 WebGL2 几何展示。所有新建的货物尺寸和重量示例仅用于演示，**不代表实际厂家型号**。

## V1.0 本轮新增与安全边界

- **物理基础渲染 PBR**：离线自生成的颜色/法线/粗糙度三贴图，金属度参数、GGX 微表面高光、双方向光、柔和环境光、色调映射。材质参数分别对应纸箱、木箱、托盘、板材、金属、标签纸、塑料、桶体、吨袋和卷材 10 类视觉表面。底层采用原生 WebGL2，无 CDN 或 npm 运行依赖。
- **材质开关**：在「显示」菜单中关闭「真实材质光照 PBR」以减小 GPU 运算压力。Canvas 降级模式仅保留几何和简化色彩，不会展示 PBR 完整效果。
- **自由编排**：自由摆放的「编辑已装」区新增 X/Y 方向对齐、X/Y 等间距排列。每次整体校验碰撞、柜壁越界、数量、基本支撑与重量，失败时不保存。
- **撤销 / 重做**：顶部增加重做按钮；Ctrl/⌘+Z 撤销，Ctrl/⌘+Shift+Z、Ctrl/⌘+Y 重做。正常编辑建立新的撤销历史后，旧重做历史被清空。
- **设计与操作**：更清晰的浅色装柜工作台，分离货物库、装载编辑室与三维画布；保留小数显示、XYZ 坐标和订单/组别编号追溯。
- **数据兼容**：沿用既有 JSON 装柜方案和 `.csv`/`.xlsx` 导入字段；浏览器优先读取 `realload-v10`，在没有新版数据时会尝试旧版本地草稿。

**材质真实性说明：** 目前是具备 PBR 光照响应的程序化通用材质，**没有使用照片扫描贴图**，也没有模拟纸张真实纤维强度、木材含水率或钢板结构特性。材质看起来像真实包装不等于有经过检测的材质规格。若要做到特定厂商/货品照片级一致，后续必须加入授权采集的实拍 PBR 贴图与实物尺寸验证。

**安全边界：** 现有验证仍以包装外包络、轴对齐矩形、柜门基本净空、碰撞、基础支撑和总质量为主。尚未验证叉车轨迹、吊装、动力学、集中轮压、绑扎承载、纸箱抗压和合法 VGM；严禁把基础几何通过误认为实际运输安全批准。标准参考见 IMO/ILO/UNECE CTU Code：https://www.imo.org/en/OurWork/Safety/Pages/CTU-Code.aspx 。

**已执行的验收：** Node `npm test` 中 67 项通过；Chromium 离线页面注入验证了导航、自由编排入口、PBR 选项、单件删除/撤销/重做、无脚本错误。测试环境 WebGL2 GPU 被禁用，**不能宣称已完成 GPU 实机画质/帧率验收**。

## 一、启动

Mac/Windows 安装 Node.js 20+ 后，在解压得到的 `RealLoad-Studio-v1.0` 目录运行：

```bash
npm run dev
```

浏览器打开 **http://localhost:4184**。另一个端口可用 `PORT=4300 npm run dev`。不需要执行 `npm install`，没有第三方运行时依赖。使用 `npm test` 运行全部测试。

## 二、新增「自由摆放」模块

1. 顶部选择 **自由摆放**，左侧出现待装货物列表；列表中每张卡片显示 SKU、包装材质、外尺寸、订单组、首个具体箱号及剩余数量。
2. **拖拽卡片到场景**：以鼠标松开处的地板坐标为参考，按目前的步长放置，实时检查尺寸、柜门、边界、碰撞、数量、重量和基础支撑。无效位置拒绝保存，并提示原因。双击卡片可按已有启发式逻辑快速放入一件。
3. **选中并移动**：点击场景货物，拖动货物本体移动平面位置，或拖动 X/Y/Z 三轴手柄单轴移动。精确坐标可以到原有「操作」页输入小数。
4. **多选**：Shift/⌘ 点击添加或取消选中。选中同组、全部选择、取消选择，并可批量移动、旋转、移出、锁定。
5. **批量移动**：可设置 1/5/10/25/50/100/250 mm 步长，分别沿 X/Y/Z 正反方向移动。整组选中情况下拖动其中一件，会同步预览同组选中货物的移动。
6. **校验**：移动、转向、移出都按整批结果重新验证。不允许因删除下方货物导致已装货物悬空。位置不合规的改动不会写入项目。
7. **显示层**：三轴坐标线、逐件 XYZ 数值和单件标签均有独立开关；全局显示菜单还可控制网格、箱壁透明度、显示小数位、四视图。

坐标定义沿用旧版：**X 为箱体长度、Y 为箱体宽度、Z 为离地高度**。所有保存值都是毫米；渲染时换算成米。拖放点位是货物底面中心，吸附后再计算左下后方角点。自由透视中，后备 Canvas 的屏幕投影是近似定位，正式装柜需再次核对精确 XYZ。

## 三、货物扩展：8 类包装

| 类型 | 可视化构成 | 当前装载计算方式 | 必须另行验证 |
|---|---|---|---|
| 瓦楞纸外箱 | 纸板纹、封箱带、标签 | 实测外包络长方体 | 纸箱抗压、遇潮性能 |
| 木制出口箱 | 木纹、横纵加固条与护角 | 实测外包络长方体 | 木箱结构、底部承载、木质检疫 |
| 缠膜托盘货 | 托盘支脚和面板、托上包装 | 整托外包络，不重复计入内箱 | 托盘承载、绑扎、突出尺寸 |
| 木板 / 板材 | 木纹、分层边线 | 实测外包络长方体 | 变形、支撑点与捆扎 |
| IBC 液体周转箱 | 罐体、金属笼、底座 | 外接长方体 | 液体晃动、叉装、重量分布 |
| 钢桶 / 塑料桶 | 圆柱筒体、加强筋与桶盖 | **保守外接长方体** | 防滚动、系固、堆垛 |
| 吨袋 / FIBC | 柔性袋体、绑带、吊带 | **保守外接长方体** | 吊装方式、变形、承压 |
| 纸卷 / 卷材 | 圆柱体、端部卷芯 | **保守外接长方体** | 防滚动、朝向、系固 |

⚠ 圆柱体的视觉模型是圆形，**但算法暂时没有实现圆桶错列紧排、卷材非矩形相互嵌套，也没有连续叉车/吊装路径模拟**。不能把“外观像实物”理解为“力学模型已完全还原”。新增品类的初始值只是可编辑示例，不是官方标准尺寸。

可从 `examples/八类包装与箱件编号-演示.csv` 导入这些包装类型。文件中的重量、尺寸、订单号均为虚构测试值。

## 四、外贸编号与导入

保留 `.csv`、`.tsv`、`.xlsx` 字段映射与单位自动换算；支持订单号、货物组别、批次、产品 SKU、箱号、托盘号、尺寸与单件毛重等字段。

- **SKU** 是产品/货物识别码，不能代替具体外箱或托盘号。
- **来源实物编号** 优先保留源表输入，如 `CT-001`、`PAL-001`。
- **缺失编号** 自动生成 `PLAN-...` 内部规划号；新增包装类型使用不同的尾码（IBC、DR、BG、RL 等）便于辨别，但均**不是 GS1 SSCC**。
- **同 SKU 跨组** 仍保留独立记录，导出可以核对每件对应的订单组和 XYZ。
- 可在单件检查器查看货物类型与尺寸，并生成已装坐标 CSV 和逐件编号对照清单。

## 五、渲染与性能

原生 WebGL2 渲染继续采用真实三维顶点、深度缓冲、程序化纹理和光照；V0.9 起加入圆柱三角网格、IBC 框架、吨袋构件，不只是颜色区别。三维视图的相机和射线选取沿用本地实现，没有从 GitHub 仓库复制不明授权代码。无 WebGL2 时沿用 Canvas 后备视图，但**Canvas 对圆桶等非矩形外观表现不完整**。

本次容器 Chromium 无法完成有效的 GPU 端到端截图，WebGL2 真实帧率、透明排序及操作仍需你在 Mac Chrome/Safari 上检查。新增加了 `tests/free-studio.test.mjs`、`tests/v09-ui.test.mjs` 等几何和页面契约检查。**自动化测试通过不能代替实机视觉验收**。

## V1.3：材质照片与框选编辑

1. **自定义材质照片**：点击装载场景顶部「材质」打开管理面板。选择牛皮纸、木箱、板材、托盘、钢板、塑料等类别，可上传 JPG / PNG / WebP（小于 12 MB）；软件缩放为 512×512 JPEG，在浏览器本地保存后用于 WebGL2 材质底色及估算的法线/粗糙度。支持恢复默认纹理。照片只存在当前浏览器本地，**不会随装柜 JSON 导出**；其他电脑需要重新上传相应贴图。
2. **自由摆放框选**：点击左侧「自由摆放」，在 3D 场景空白处按住 Shift 然后拖出选区，可同时选多件。已有选区会合并；点击「清除选择」可重新开始。其他批量操作仍经过几何与支撑检查。
3. **编号定位与位置方向**：柜头在 X=0，柜门在 X=L；货位图左边是柜头、右边是柜门。单件坐标的工程数值仍优先于区域描述。
4. **限制**：本版没有把外网 CC0 图片原文件打包进 ZIP。项目使用已有程序化默认材质，用户可从 CC0 素材站下载并上传实拍照片。没有实测物理法线/粗糙度、叉车路径、抗压、固定和 VGM 认证。Canvas 降级模式不会显示新的 WebGL 材质照片。

素材来源及合法获取路径见 `MATERIAL-SOURCES.md`。
