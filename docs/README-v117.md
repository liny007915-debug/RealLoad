# RealLoad Studio V1.9 · 智能落位与独立装卸预演

## 推荐操作

1. 顶部「导入表格」或左侧「新建货物」。示例 16 类 CSV 在 `表单与检验/05-可导入-16类包装示例.csv`。
2. 「自由摆放 → 编辑已装」逐件选择，鼠标右键可旋转 90° / 180°，按住 Shift 多选。
3. 大/长柜可按 `C` 聚焦一件远端货物，`WASD` 旋转观察、`Shift+WASD` 平移、`+/-` 或滚轮缩放、`F` 复位。点击画布空白处拖动旋转；空白处按右键拖动平移。
4. 90° 旋转修改水平尺寸并执行碰撞检查；180° 不改变占地尺寸，但会保留 `heading` 朝向供显示及导出。
5. 视图用途：立体用于编辑、俯视定位 X/Y、正视查看门口 Y/Z、侧视查看 X/Z、四视图做对照。

注意：异形货物按最大外包络占位；仅规则直立正圆筒之间使用圆形 XY 碰撞测试。圆盘、托盘及异形承压、绑扎、防滚、叉车路径尚不具备工程认证。照片级 PBR/WebGL2 最终效果需要在真实 Mac GPU 上确认。

# RealLoad Studio V1.7｜从装箱单到真实货位

**这是一款本地运行的集装箱装载规划原型。** 无需登录、无需 npm 安装依赖；货物资料、导入内容及材质上传数据默认在本机处理。容积、坐标和重量以实际输入为准，但外观与部分安全计算属于可视化简化模型。

## Mac 一键打开

1. 解压 `RealLoad-Studio-v1.7-Mac-OneClick.zip`，进入 `RealLoad-Studio-v1.7` 目录。
2. 右键 `启动RealLoad.command`，选“打开”。若系统阻止执行，请在安全设置中允许该脚本。不要执行来源不明的其他脚本。
3. 首次启动时会检测 Node.js 20+，随后自动打开浏览器。默认地址 **http://127.0.0.1:4191/**。若端口占用，启动器会选择 4192–4205 的空闲端口；以终端实际显示的地址为准。
4. 在浏览器操作。停止服务可以双击或右键 `停止RealLoad.command`。

手动启动：

```bash
cd ~/Downloads/RealLoad-Studio-v1.7
npm run dev
```

如 `node` 未安装，请前往 https://nodejs.org/ 安装最新受支持的稳定版（本项目要求版本 20 以上）。程序启动时**不联网下载依赖**。本地网页只在自己电脑上运行。

## 第一次打开：三步，不用先懂 XYZ

### 第一步：准备货物（清单）

默认给出四种**虚构练习 SKU**，柜体保持空置，方便先拖一件练习。你可以直接选择左侧的 SKU，点击货物旁边的 `+` 放入一件；也可以点“导入表格”进入三步导入核对，支持 CSV、TSV、XLSX。

**输入数据规则：** 外包装长宽高（mm）、每件毛重（kg）、数量、SKU、所属订单和组别。实际箱号优先从源表读取；无号码则使用 `PLAN-` 规划号，不能假装真实贴标。

### 第二步：自由摆放（场景）

- 左侧导航点击“自由摆放”，从货架拖一件到柜体地板；放不下会显示碰撞、越界或支撑错误。
- 点击某件箱子进行选择：直接拖动、在操作面板输入 XYZ 毫米坐标，或选择 `精确贴边`。
- 可以 Shift+点击多选或在空白区 Shift 拖框；支持整组选中、移动、对齐和旋转。任何不满足当前约束的变动都会被拒绝。
- 鼠标滚轮缩放，拖动画面空白区域旋转视角。顶部视图栏可选自由立体、俯视、正视、侧视、四视图。
- 新版**选中货物后不会自动切换导航**，直接点击画布旁“调整位置”才进入详细编辑。

**贴边坐标：** 靠柜头 X=0；靠柜门 X=箱长−货长；贴左壁 Y=0；贴右壁 Y=箱宽−货宽。四种操作均以整个货物外廓验证，不是简单把中心点推到墙上。

### 第三步：定位和导出

- 在场景中选择“编号定位”，输入外箱号、SKU、PO 或组别；平面小地图可以直接点击相应位置。
- 选中货物后，下方会显示“柜头/中段/柜门侧”“左右侧”“上中下层”及精确 XYZ 坐标。
- 点击顶部“更多”→“导出”可导出 JSON 完整方案、已装坐标 CSV、按箱号的逐件清单 CSV。
- 出口托盘/整箱等物流单元编号必须以仓库实际标签、订单信息为准；软件生成的规划号不是 SSCC。

## 真实材质与显示

- 支持14类货物：瓦楞纸箱、木箱、整托托盘、板材、IBC、桶装、吨袋、卷材、塑料周转筐、编织袋、机械设备、电缆盘、管材束、保温箱。
- V1.7 保留 V1.6 的 **Canvas 降级模式**增加了按包装材质的离线程序化纹理（木纹、纸板纤维、织物、金属细纹）和简化接触阴影；WebGL2 继续保留既有程序化 PBR 光照与用户材质照片替换入口。新算法不会改变尺寸、毛重和碰撞外廓。
- 想使用你自己的包装照片？点击场景工具栏“材质”→选择包装类型→上传本机 PNG/JPEG/WEBP 图片，可影响 WebGL2 表面的颜色纹理。照片不自动推导包装强度或规范参数。
- **重要限制：** 没有内置经摄影扫描的真实厂商贴图库，纹理仍是模拟纹理；如果浏览器不支持 WebGL2，会自动回退 Canvas，不能把截图误认为最终 GPU 画质。

## 我们现在实际验证了什么

**已经验证：** 毫米尺寸转换、轴向矩形外包络碰撞、基本内部边界和质量检查、支持的旋转朝向、数量与标签导入、Excel 解析、部分成组摆放、贴边算法等；V1.7 自动化测试 `113/113` 通过。浏览器交互在隔离的 Chromium Canvas 降级模式下通过，桌面与 390px 手机宽度无横向溢出和脚本错误。

**没有验证：** 真实 GPU 帧率、摄影测量材质、曲面物体的精确紧密装载、单件承压、底板集中载荷、叉车/门口连续搬运路径、绑扎防滚、运输动力学、VGM 或特定国家运输法规的全部要求。**几何检查通过，不等于实际装柜或运输安全合格。** 实务请核对 CTU Code 和设备制造商/船公司规格，并现场检查。

## 疑难排查

- **页面打不开：** 先运行 `启动RealLoad.command`；查看 Mac `~/Library/Logs/RealLoad-Studio-v1.7.log`，或在终端运行 `npm run dev` 查看提示。
- **打不开拖拽：** 进入“自由摆放”，确保左侧 SKU 有剩余数量，货物未被锁定。按货物完整尺寸计算，贴边前留足空间。
- **看不到真实材质：** 检查场景模式与“显示”选项；如果状态显示 Canvas 降级模式，WebGL2 PBR 和自定义照片贴图不适用，Canvas 只显示离线模拟纹理。
- **导入 XLSX 显示错误：** 使用完整工作簿的第一张工作表，检查有无空白头行、合并单元格和含公式的单元格；可先转换 CSV。
- **不小心移动错了：** 顶部“更多”→“撤销”，也可按 `⌘Z`。
- **重新显示新手步骤：** 点击左下角“说明”或工作台“使用指引”。

更多历史版本技术变更：`docs/历史说明-V15.md`；本轮详细信息：`V16-版本改进与验收.md`。


## V1.7 交互设计与改进（首次学习约 1 分钟）

新版将左侧竖栏改成 **顶部水平导航**，让三维货柜画布获得更大视野。左侧面板只显示当前工作所需的数据：在「自由摆放」中「拖入货物」和「编辑已装」是两个真正互斥的工作模式。

1. **编辑已装**：顶部点击「自由摆放」→ 左侧选择「编辑已装」，立即出现所有装入件清单。可以搜索箱号、筛选组别，单击选中、Shift 多选；右侧场景会同步高亮。
2. **管理分组**：点击「货物」→「管理分组」。可选择原组，选中所需 SKU，并填写新的组名、点击「将所选 SKU 移入目标组」；也可点击「重命名此组」。组别只是分类，不会移动货物几何位置；未实际贴标的 PLAN 编号会重新按组生成，来源提供的编号不变。
3. **按组操作**：货物清单每组都有「选中已装」。在自由摆放里也可以筛选组别→「选中此组」。随后旋转、锁定、沿三轴移动、贴边及移出均针对选区重新验证。
4. **右键货物**：在三维场景或「编辑已装」清单中右键任意一件货物，可精确编辑、按编号定位、选中同组、旋转 90°、锁定、再放入一件、复制编号或移出。Mac 触控板的双指点按也可以触发。
5. **键盘**：按 `?` 查看快捷键面板。常用 `E` 编辑已装，`P` 拖入货物，`G` 选同组，`K` 锁定，`R` 旋转，`Shift+F10` 打开右键菜单，`⌘/Ctrl+A` 选全部，方向键移动 XY，`PageUp/PageDown` 升降 Z，`Shift+方向键` 精细移动，`Alt+方向键` 大步移动，`Delete` 移出，`Esc` 关闭菜单。

**数据及安全边界**：以上操作与现有外包络检查联动，不代表货物可以绕过障碍完成真实装卸。改动不增加货物强度或法定载重验证，也不意味着所有材质已经实现实拍 PBR。图形回归在 Canvas 后备渲染下完成，真实 GPU WebGL2 画质仍需 Mac 设备复测。

## V1.15：小屏相机适配与急件优先（模拟）

- 货柜场景按实际容器大小、视角和画布宽高比拟合八个顶点；俯视、正视、侧视使用各自的正交适配。小屏不用以滚动整个页面来补救三维模型被裁切。
- 手机上无侧栏时场景可一次显示；打开货物清单后，货柜保持在上半屏，清单在下半屏独立滚动。按“适配”可复位全柜，按 Shift+F 全屏精细编辑。
- 货物表支持紧急、优先、普通、可后卸；CSV/XLSX可导入「紧急程度」列，SKU编辑器也可更新。优先级单独修改不会清空已有坐标。
- 急件自动装载时先尝试门口附近的几何候选位置；卸货建议对**当前实际可取**货物优先安排急件，无法取出的急件必须先处理阻挡件；所有步骤仍按门洞/支撑/碰撞模型验证。
- 支持按「急件优先」筛选，清单和时间线显示优先级及受阻原因。**不保证急件一定能最先卸出，也不能代表叉车作业可达性。**
- `V115-多场景测试表单` 含 10 个 CSV 场景与可编辑 XLSX；执行 `node V115-多场景模拟.mjs` 可重新计算三柜型共 30 组输入，并生成 CSV/JSON 结果。
- 完整限制、边界与测试见 `V115-升级与验收.md`。
