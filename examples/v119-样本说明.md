# V1.19 可交互货物样本

这三组均为模拟数据，尺寸和毛重不是厂家规格，也不是运输安全认证。长度使用 mm，毛重使用 kg，编号均为 PLAN 规划编号。请使用实测的运输包装最大外廓替换示例值。

| 文件前缀 | 内容 | 已放置件数 |
|---|---|---|
| `v119-daily-mixed` | 纸箱、整托、钢桶、卷材、编织袋、木箱 | 11 |
| `v119-irregular-equipment` | 非对称设备、机箱、木线盘、管材捆、圆柱包装 | 7 |
| `v119-door-support-boundaries` | 门洞临界箱、上下支撑箱、禁止承托的软袋与异形件、旋转箱 | 6 |

每组提供 JSON 和 CSV。JSON 含合法预置坐标，可在备份当前方案后导入并直接编辑、旋转及逐件预演。CSV 只有订单货物资料，导入时仍需核对字段、单位和确认页，不包含原布局；CSV 导入默认一层，不能代替完整 JSON 方案备份。

异形设备的凹口、木线盘孔和管间间隙都只是视觉表达，不能嵌套其他货物。异形、软袋、线盘和管材捆不能作为完整平面支撑。直立且等直径的圆柱间沿用圆形碰撞；与异形及其他包装组合仍采用保守的最大长方体外廓。

边界场景默认净空为 0 mm，门洞临界箱宽 2340、高 2292，Y 为 6，恰好处于示例 20GP 居中门洞内。增加净空或向门洞外偏移 0.01 mm，严格直线路径应拒绝；将上箱抬高 0.01 mm 应提示缺少支撑。预演仍只模拟固定 Y/Z 沿 X 轴直线运动，不包括叉车、吊装、侧移、承压、绑扎和动态稳定性。
